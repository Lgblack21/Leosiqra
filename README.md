# Leosiqra

Cloudflare-first Next.js application.

Pindah ke komputer baru? Lihat [SETUP.md](./SETUP.md) untuk hal-hal yang tidak
ikut lewat `git clone` (env file, login Cloudflare/GitHub).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy (Cloudflare)

```bash
npm run cf:deploy
```
